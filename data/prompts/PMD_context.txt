Context: We study line-level defect prediction on real-world Java software projects. Each instance corresponds to a single source-code line. A line is labeled as buggy if it is marked as defective by the dataset's ground truth (e.g., via links to bug-fixing commits). For each line, we derive features from PMD's built-in Java rules. Each feature is encoded by the PMD rule name (i.e., the rule's identifier), and its value indicates whether PMD reports a violation of that rule on the line (1 = violation, 0 = no violation).
