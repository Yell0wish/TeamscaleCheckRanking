Context: We study line-level defect prediction on real-world Java software projects. Each instance corresponds to a single source-code line. A line is labeled as buggy if it is marked as defective by the dataset's ground truth (e.g., via links to bug-fixing commits). For each line, we derive features from Semgrep's Community Edition Java rules. Each feature is encoded by the Semgrep rule ID (i.e., the rule's identifier), and its value indicates whether Semgrep reports a finding (i.e., the rule matches) on the line (1 = matched, 0 = not matched).
